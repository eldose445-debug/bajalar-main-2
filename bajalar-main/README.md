# Bajalar

Create a premium, modern, fully responsive website for a digital and AI agency called 2BAJA.

Brand identity:

* Brand name: 2BAJA

* Industry: Website development, AI automation, digital solutions.

* Design style: Premium, minimalist, modern.

* Main colors: Black (#080808), dark gray (#121212), gold (#C9A45C), white.

* Use elegant typography, smooth animations, subtle gold effects and clean layouts.

* The website must look professional and trustworthy.

IMPORTANT: LANGUAGE

The website must support ONLY TWO languages:

1. Kazakh (default language)

2. Russian

Add a working KZ / RU language switcher in the header. All website text, buttons, menus, service descriptions and contact sections must change when the language is switched. Do not use English for visible website content.

Website structure:

1. HEADER

* 2BAJA logo

* Navigation menu

* Services

* About Us

* Projects

* Contacts

* KZ / RU language switcher

* Gold “Contact Us” button

2. HERO SECTION

    Kazakh headline: “Болашақ бүгіннен басталады.”

    Russian headline: “Будущее начинается сегодня.”

Subtitle:

Kazakh: “Бизнесіңізді жаңа деңгейге көтеретін цифрлық шешімдер.”

Russian: “Цифровые решения, которые выводят ваш бизнес на новый уровень.”

Add two buttons:

* “Қызметтеріміз” / “Наши услуги”

* “Бізбен байланысу” / “Связаться с нами”

3. SERVICES SECTION

    Create four premium service cards:

* Website Development / Сайт әзірлеу / Разработка сайтов

* AI Automation / AI автоматтандыру / AI-автоматизация

* E-commerce / Онлайн сауда / Онлайн-торговля

* Digital Solutions / Цифрлық шешімдер / Цифровые решения

Each card should have an icon, short description and subtle hover animation.

4. ABOUT SECTION

    Explain that 2BAJA is a young digital agency helping businesses grow through websites, AI and automation.

5. PROJECTS SECTION

    Create a modern portfolio section with attractive project preview cards. Use clearly marked demo projects until real projects are added.

6. WHY CHOOSE US

* Modern technologies

* Individual approach

* Quality and reliability

* Business growth

7. CONTACT SECTION

    Add a contact form with:

* Name

* Phone number

* Service selection

* Message

* Submit button

Add WhatsApp and Instagram contact buttons with editable placeholder links. Do not invent real contact details.

8. FOOTER

* 2BAJA logo

* Navigation links

* Social media links

* Copyright © 2026 2BAJA

TECHNICAL REQUIREMENTS:

* Fully responsive for desktop, tablet and mobile.

* Smooth scrolling and animations.

* Functional navigation.

* Working Kazakh/Russian language switcher.

* Modern reusable components.

* Clean, professional design.

* Make the website fast and easy to use.

Build the complete homepage, not just a design mockup. Make it look like a real premium digital agency website.
